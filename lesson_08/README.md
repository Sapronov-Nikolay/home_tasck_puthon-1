1. Установите зависимости (если ещё нет):
   ```bash
   pip install -r requirements.txt

2. Проверьте наличие уcтановленного Python
3. после клонирования репозитория откройте терминал в папке `lesson_08`.
4. Запустите `run.bat` (Windows) или `./run.sh` (Linux/macOS).

    - `python setup_env.py` (введите логин и пароль)

Скрипты сами создадут виртуальное окружение, установят зависимости,
получат CompanyID API-ключ, запишут их в `.venv` и запустят тесты.

## Управление API-ключами (токены)

YouGile ограничивает количество активных ключей до 30 шт. И это блокирует возможность дальнейшей работы.
Если в процессе работы насоздавались 30 токенов, то 31 уже не будет работать и работа будет заблокирована.
Система позволяет очищать скопившиеся токены.

- `python key_manager.py --list` - посмотреть сколько ключей (токенов) или какие есть в данный момент.
- `python key_manager.py --clean` - удалить все токены, кроме текущего и добавить (обновить) в `.venv`.

## Особенности

- Тесты создают проект с уникальным название и скрывают его после выполнения (`"deleted": true`)
- API не принимает `description` при обновлении – негативный тест проверяет это.
- Ключи автоматически обновляются, если текущий устарел.
