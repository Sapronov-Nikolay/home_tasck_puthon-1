# UI-автотесты с Allure-отчётами

Проект содержит набор автоматизированных UI-тестов, написанных с использованием **Page Object Model** и покрытых **Allure** для наглядной визуализации шагов и результатов.

## 📦 Особенности

- Тесты для формы валидации, медленного калькулятора и интернет-магазина
- Паттерн Page Object
- Allure-декораторы: `@allure.feature`, `@allure.story`, `@allure.title`, `@allure.description`, `@allure.severity`
- Шаги (`@allure.step` и `with allure.step`) для детализации
- Скриншоты при успешном прохождении

---

## 🔧 Требования

- Python 3.8+
- Браузеры: **Google Chrome**, **Firefox**, **Microsoft Edge** (убедитесь, что установлены последние версии)
- Allure Commandline (инструкция по установке ниже)

## 📥 Установка Allure Commandline

### Windows

#### Вариант А — ручная установка (без менеджеров пакетов)

1. Скачайте последнюю версию **Allure Commandline** с официального репозитория:  
   👉 [https://github.com/allure-framework/allure2/releases](https://github.com/allure-framework/allure2/releases)  
   Выберите архив `allure-<version>.zip`.

2. Распакуйте содержимое архива в папку, например:  
   `C:\Program Files\allure`

3. Добавьте путь `C:\Program Files\allure\bin` в **переменную окружения `PATH`**:
   - **1-й вар.** Откройте **Панель управления** → **Система** → **Дополнительные параметры системы**.
   - **2-й вар.** нажмите **Win+R** → введите **sysdm.cpl** → Нажмите **ОК** → Откроются **Свойства системы** → Перейдите во вкладку **Дополнительно**
   - Нажмите **Переменные среды**.
   - В разделе **Системные переменные** или **Переменные среды пользователя для `name-user`** найдите `Path` и нажмите **Изменить** или двойным кликом мыши.
   - Нажмите **Создать** и вставьте `C:\Program Files\allure\bin`.
   - Нажмите **ОК** во всех окнах.

4. Закройте и откройте новое окно командной строки (CMD) и проверьте установку:

```bash
allure --version
```

## Примечание: папки `allure-result` и `allure-report` добавлены в `.gitignore` и не должны пушиться в репозиторий.

---
### Запустите тесты с сохранением Allure-результатов
#### Если хотите запустить все тесты в папке:
```bash
pytest . --alluredir=allure-result
```
- Если вместо точки прописать имя тест-файла, то выполнится только он.

#### Проверьте, что папка `allure-result` создалась и содержит файлы `.json`
Для Windows
```bash
dir allure-result
```
Для Linux / macOS
```bash
ls allure-result
```

### Сгенерировать и открыть Allure-отчёт в активной среде виртуального сервера
```bash
allure serve allure-result
```

### Если надо, то сохраните отчёт в статическую папку для просмотра позже:
```bash
allure generate allure-result -o allure-report --clean
```

### Открыть можно по команде в любом браузере который используется по умолчанию:
```bash
allure open allure-report
```
